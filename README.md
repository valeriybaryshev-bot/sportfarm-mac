# Sport Farm для Mac

Окно-оболочка программы склада ООО «СПОРТФАРМ»: открывает сайт https://sf.clashofimperia.ru в своём окне.
Данных, паролей и ключей здесь нет. Облачный Mac GitHub (Actions) собирает из `app.zip` (папка программы) файл .dmg
и кладёт его в «Releases»; сервер склада раз в час берёт последний выпуск — его скачивают через
https://sf.clashofimperia.ru/download с Mac.
